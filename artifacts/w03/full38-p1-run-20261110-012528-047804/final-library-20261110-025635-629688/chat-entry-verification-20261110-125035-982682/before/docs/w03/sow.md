# 青禾会员报表问数阶段范围说明

版本：v0.12-draft，2026-11-10。供阶段讨论与核查。本版整理交付范围并更新工程进度；预算、合同、试点、正式上线和验收批准仍需另行确认。

## 目标与阶段安排

本期先在指定合成测试数据中实现可追溯、可核对的会员报表问数，交付计算口径、查询结果、验证记录和待确认事项，支持讨论下一步验证什么、由谁补充依据。

业务优先关注会员范围与复购下滑问题。连续四季度下滑尚待实际报表核实，会员老化属于待验证假设；测试数据不能证明真实经营趋势或原因。本期暂定规则下的试算不作为总部付费资格已核定的证明，也不据此开展真实资格认定或原因分析。不承诺复购提升、节约工时、费用金额或投资回报。

## 六项付费会员月报的暂定口径及确认依赖

本期统计确认邮件已指定运营与门店作为卡产品范围及有效状态的确认渠道。按该渠道取得的卡种、日期和多卡说明，是本期月报实现的业务依据。当前暂定标记用于保留受访者尚未明确确认的部分，不表示这些访谈不能引用，也不要求另行批准后才可作为依据。

六项为月末付费会员购买人数、有效订单数、净销售额、复购人数、复购率及订单均额。目前已实现并完成暂定口径下的工程核对，**门店日期规则用于总部月报仍待书面确认**；暂定试算不能直接作为正式总部报表或考核依据。

已明确本期只纳入悦享年卡和家庭季卡，依据卡类型及有效状态判断，不以会员等级或支付金额代替资格。同一账户有多张符合条件的卡，不重复计算账户和订单。月报以自然月最后一天判断账户资格，再统计这些账户当月全渠道、全门店的有效订单，不要求每笔订单发生时已有资格。

当前试算采用的日期假设为：生效当天起有效，计划到期当天及提前终止当天起无效；提前终止为空仅表示没有提前终止记录，不延长计划有效期。日期正常且两个结束日均有记录时，判定日须早于两个结束日。提前终止晚于计划到期等矛盾记录先核查，不将其直接按有效或无效计算；若存在此类记录，当前数据前置检查会阻止继续试算。另一张正常卡能否形成资格按已取得的逐卡规则记录，但不据此跳过异常记录核查。

| 待确认事项 | 建议协调与配合安排 | 对交付的影响及解除条件 |
| --- | --- | --- |
| 已采用日期规则的书面确认、正常双结束日组合的细节及例外 | 项目组协调运营提供适用于本期的权益或统计口径依据；具体牵头人、提供人、最终确认人及时间待落实 | 未确认前保留暂定试算标记，不认定总部资格规则已核定；取得书面依据后核查适用对象及日期边界 |
| 矛盾日期记录的处理及更正依据 | 业务侧核查实际记录，IT配合字段与关联核对，门店提供办理条件 | 核查前不得擅自判定矛盾卡有效或无效；需明确处理依据、记录和责任，才能解除相关数据阻断 |

取得确认后，交付方评估对实现、测试、费用和计划的影响；若依据与暂定规则不同，应修订并重新验证。缺失依据不导致自动缩减38项目标、自动延期或自动验收，必要调整须按变更流程确认。

## 后续范围与本期排除项

后续可讨论生产数据准备与接入、条件圈选、运营建议、人工采用流程及效果观察。圈选条件与名单用途须单独书面明确，本期问数能力不代表已具备圈选或自动触达能力。

本期排除生产上线、真实营销执行、权限代办、跨系统自然人统一、门店考核调整及业务收益保证。任何生产数据使用、试点或触达活动均需另行落实范围与授权。

可比任务的建议判定标准：业务目的、指标定义及时间口径一致；门店/渠道范围、输出粒度、交付格式、复核要求和完成定义一致；数据准备及清洗工作边界一致。数据量级、数据质量、任务难度及操作者经验须记录，并按启动前共同确定的分层规则比较，不临时挑选有利样本或事后设阈值。工具使用方式是拟观察的差异，不要求两期工具相同；其他影响因素的变化必须留痕，简单前后比较不等于因果证明。

每项任务保留可比判定及理由。关键条件不同、必要时长记录缺失或无法形成可比组时，保留原记录并单列说明，不进入节省工时推算；全部任务量和缺失/不可比数量仍须展示。清单或口径变化记录新版本及影响范围，双方确认后另组比较；不改写已采集原记录。必要时提出补采或延长观察建议，经另行确认再实施，不自动延长本期交付期限。

真实运行须先取得必要的数据使用与试点授权，完成适用范围确认、系统就绪核对及人员安排。上述前后观察只能描述差异，人员熟练度、数据量、任务难度等变化可能影响结果，不能直接认定因果收益。

复购变化单列后续研究：在实际运营干预具备条件后，另行明确干预动作、对象、自然月观察窗口和对照方法。建议在业务允许时设置同期可比对照，并记录活动、价格、季节等变化；具体分组方法、周期及负责人需另行评审，不能套用上述工时观察周期。若缺少可支持归因的设计，则只报告描述性变化，不归因为问数工具。不以合成测试结果或相邻月份差异承诺收益，收益目标尚未约定。

## 未决事项及变更处理

当前仍须落实总部付费资格规则及书面适用依据、材料提供人与最终确认人、评审组织及授权范围、实际工作量与计费依据、费用承担方，以及后续效果观察的人员和启动条件。
