在新环境复跑：
1. 解压课程c16工程，按课程说明安装Python和依赖，准备原始small/large数据及模型配置。
2. 将提交文件按仓库相对路径放入工程工作副本。本轮新增构建材料09、10也须恢复到materials/w03/，用于重建指标库。

4. 在工程根目录运行以下命令。项目和输出使用新目录；Windows原生终端将.venv/bin/python换为.venv\Scripts\python.exe。

.venv/bin/python -B tools/w03.py load --library artifacts/w03/library --data materials/data/small --project .runtime/qinghe-submit38-small-v1
.venv/bin/python -B tools/w03.py load --library artifacts/w03/library --data materials/data/large --project .runtime/qinghe-submit38-large-v1

以下测试调用模型；执行前配置自己的访问凭据，凭据不随作业提交：
.venv/bin/python -B tools/w03.py test --project .runtime/qinghe-submit38-small-v1 --cases customer/w03/tests-small.json --output artifacts/w03/retest-submit38-small-v1 --judge-command .venv/bin/python customer/w03/judge_full38.py
