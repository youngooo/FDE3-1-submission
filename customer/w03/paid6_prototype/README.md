# 六项付费月报聚合原型

状态：开发验证。当前正式指标库仍为 32/38 项；本原型不注册产品指标，不代表六项资格规则已确认或验收通过。

依据：材料04已规定先确定账户月末资格，再统计这些账户当月全渠道、全门店的有效订单。有效订单沿用材料01/02的 paid 且实付减累计退款大于零。六项计算包括购买账户数、有效订单数、净销售额、复购账户数、复购率和订单均额。

`paid6_prototype.py` 只实现取得资格结果后的聚合。调用者提供完整的账户×月份资格表，每个布尔值都必须明确；缺失、未知和重复记录报错。人工测试资格不是客户事实，不能用来回答青禾的付费会员人数。

`check_paid6_prototype.py` 使用手工订单、人工资格表与预先列示的算术期望，检查跨月、跨门店和渠道、部分退款、取消和全退、重复输入、零分母、覆盖范围及未知资格处理。重复资格记录被拒绝，只验证聚合接口不接受重复输入，不证明上游多卡资格算法正确。

在工程根目录执行：

```sh
out="artifacts/w03/paid6-prototype-check-$(date +%Y%m%d-%H%M%S)"
.venv/bin/python customer/w03/paid6_prototype/check_paid6_prototype.py --output "$out"
```

本原型不读取 cards，不采用任何未确认的日期算法，不处理按门店或渠道拆分。完整资格表仅为开发接口，尚未做规模适配。返回金额为分，零分母为 null，多月分别返回。
